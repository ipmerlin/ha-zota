# ZOTA для Home Assistant

Интеграция котла **ZOTA MK-X** через облачный протокол ZOTA Net. Устанавливается через HACS и настраивается в интерфейсе Home Assistant. AppDaemon, Chrome/Selenium и MQTT не требуются.

## Установка через HACS

1. В HACS откройте меню → **Пользовательские репозитории**.
2. Добавьте `https://github.com/ipmerlin/ha-zota`, категория **Интеграция**.
3. Найдите **ZOTA**, скачайте и перезапустите Home Assistant.
4. Откройте **Настройки → Устройства и службы → Добавить интеграцию → ZOTA**.
5. Введите логин и пароль ZOTA Net, подтвердите использование HTTP API и выберите котёл.

Минимальная версия Home Assistant: **2025.12**. В параметрах интеграции можно изменить интервал опроса: 60–3600 секунд, по умолчанию 300.

## Управление

| Сущность | Назначение |
|---|---|
| Термостат помещения (`climate`) | Уставка воздуха 2–35 °C, шаг 0,1 °C; включение и выключение котла |
| Уставка теплоносителя (`number`) | Температура воды; пределы берутся из настроек котла |
| Ограничение мощности (`select`) | Ступени мощности в кВт из контроллера; отдельное значение «Выключено» |
| Режим насоса (`select`) | Автоматически / Включён / Выключен |
| Источник термостата (`select`) | Не используется / Внешний / Внутренний / OpenTherm |
| Котёл (`switch`) | Включение и выключение |
| Погодозависимое регулирование (`switch`) | Включение и выключение ПЗА с сохранением коэффициентов |

Дополнительные настройки доступны в разделе конфигурации устройства:

- Гистерезис и поправка датчика воздуха; минимальная и максимальная уставки воды, порог предупреждения о низкой температуре.
- Уставка и максимальная температура ГВС, поправка датчика, антилегионелла.
- Точность регулирования мощности и задержка её включения.
- Коэффициент ПЗА, поправка уличного датчика, виртуальная температура помещения, автоматический переход зима/лето и его порог.
- Назначение контура насоса и задержка отключения; тип, режим и время хода клапана.
- Тип контакта внешнего термостата, реакция котла, снижение температуры и ступень мощности.
- Защита по давлению и четыре порога. Сущности изменения защиты и порогов давления, а также времени хода клапана отключены в реестре HA по умолчанию; при необходимости включите их в списке сущностей устройства.

**Режим OFF термостата выключает весь котёл**, а не только регулирование по воздуху. Изменение уставки само по себе котёл не включает. Режимы «Работа», «Пауза» и «Остановлен» отображаются как показания: их выбирает контроллер. Внутреннее расписание, внешнее управление и ПЗА могут влиять на фактическую работу при заданных уставках.

## Показания

Температура теплоносителя, воздуха помещения, улицы и ГВС; уставки воздуха и воды; расчётная температура воды; текущая и установленная мощность; давление; контур насоса и режим работы. Дополнительно: состояние выхода насоса, внешнее отключение, ошибки и предупреждения с числовым кодом.

Также читаются температуры AUX и SSR с кодом назначения входа, состояние выходов клапана, антилегионеллы и встроенного термостата, номер схемы, время контроллера, код уровня GSM, номинальная мощность и версии прошивок. Неустановленные датчики показывают `unknown`. Наличие поля в протоколе не означает наличие соответствующего оборудования.

У датчика «Программа термостата» в атрибутах находится программа, которую вернул котёл: периоды, уставки и исходные флаги. Неактивные программы могут отсутствовать в ответе. Редактирование встроенного расписания и загрузка журнала ZOTA пока не поддерживаются.

Отсутствующий или неисправный датчик возвращает `unknown`. Потеря связи делает сущности недоступными. HA показывает ответ контроллера; интеграция не подменяет его ожидаемыми значениями после команды.

## Подключение и ограничения

- В ZOTA Net 2.11.3 API учётной записи находится по адресу `http://control.zota.ru:81`. Логин и пароль передаются по HTTP без TLS. Поэтому в форме подключения есть отдельное подтверждение, **выключенное по умолчанию**. Автоматического перехода с HTTPS на HTTP нет.
- Обмен с котлом идёт через сервер из учётной записи по TCP, порт **1977**, также без TLS. Нужен доступ HA к Интернету и этому порту. Это облачная интеграция, автономная работа без Интернета не поддерживается.
- Пароль учётной записи используется только при настройке. HA сохраняет полученный пароль доступа к котлу в своём конфигурационном хранилище. Диагностика не содержит паролей, логина, серийного номера или адреса сервера.
- Поддерживается **MK-X**, пакет данных версии 1 (102 байта). Другие модели и схемы пакетов не заявлены как совместимые.
- Перед каждой командой читается свежая группа параметров; меняется только выбранное поле. Гистерезис, поправки, задержки и соседние поля сохраняются. Команда отправляется один раз, проверяются подтверждение и повторное чтение. При тайм-ауте результат может быть неопределённым: перед повторением проверьте актуальные показания.
- Одновременные команды этой интеграции сериализованы. Протокол не предоставляет атомарного сравнения версии с мобильным приложением; избегайте одновременного редактирования одной группы параметров из HA и ZOTA Net.
